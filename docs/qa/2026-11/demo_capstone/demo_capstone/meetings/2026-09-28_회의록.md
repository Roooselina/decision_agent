# 2026-09-28 임시 회의: 프론트엔드 스택

참석: 은정, 준호, 하은, 민재 (도윤은 수업)

준호가 주말 동안 RN 빌드 문제를 붙잡고 있었는데 결국 해결을 못 했다고 함. 캐시 지우고 Gradle 버전 맞춰도 첫 빌드 7분, 수정 후 리로드도 자주 깨진다고.

준호: 사실 주말에 Flutter로 같은 화면 두 개를 만들어 봤는데 핫 리로드가 훨씬 안정적이었어요. 디자인 시안 그대로 옮기기도 Flutter가 편했고.

하은: 저번에 말했던 거랑 같은 얘기네. 나는 찬성. 위젯 단위라 디자인 시스템 만들기도 좋아.

민재: 백엔드는 상관없으니까 프론트 둘이 편한 걸로 해. 대신 API 문서는 지금처럼 Swagger로 계속 간다.

은정: 이미 RN으로 한 작업이 얼마나 되는지가 걱정이었는데, 준호 말로는 네비게이션 뼈대 정도라 버려도 하루 손해라고 함.

은정: 그럼 정리할게. 프론트엔드는 React Native 대신 Flutter로 전환하기로 했다.

준호가 오늘 안에 Flutter 프로젝트 저장소를 새로 만들고, 기존 RN 저장소는 보관 처리하기로 함.
하은은 시안을 Flutter 위젯 이름 기준으로 정리해서 넘겨주기로 했다.
도윤에게는 은정이 단톡방으로 전달하기로 했고, 요구사항 문서의 프론트 항목도 도윤이 Flutter 기준으로 고치기로 함.

회의 끝나고 준호가 RN 저장소의 네비게이션 코드 중 쓸 만한 건 없는지 한 번 더 보기로 함.
민재는 Swagger 주소를 단톡방 공지에 고정해 둠.

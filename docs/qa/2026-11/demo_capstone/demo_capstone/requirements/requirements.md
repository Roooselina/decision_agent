# BookSwap 요구사항 명세

문서 관리: 도윤 / 마지막 수정 2026-10-24
ID 규칙: FR은 기능, NFR은 비기능. 우선순위 상은 MVP 필수.

## 기능 요구사항
- FR-01 학교 구글 계정(SSO)으로 로그인하며, 학교 도메인이 아닌 계정은 가입할 수 없다 (상)
- FR-02 회원가입 시 학교 이메일로 인증 메일을 보내 본인 확인을 한다 (상)
- FR-03 판매자는 교재 제목, 과목명, 가격, 상태, 거래 희망 장소를 입력해 매물을 등록한다 (상)
- FR-04 매물당 사진은 최대 5장까지 올릴 수 있다 (상)
- FR-05 교재 제목과 과목명으로 매물을 검색한다 (상)
- FR-06 구매자와 판매자는 1:1 쪽지를 주고받으며, 앱이 열려 있으면 10초마다 새 쪽지를 확인한다 (상)
- FR-07 거래 화면에서 판매자의 계좌 정보를 보여주고 복사 버튼을 제공한다 (상)
- FR-08 앱 안에서 결제는 처리하지 않고, 대금은 사용자끼리 계좌이체로 주고받는다 (상)
- FR-09 거래 요청과 새 쪽지는 FCM 푸시 알림으로 알린다 (중)
- FR-10 판매자는 매물 상태를 판매중, 예약중, 거래완료로 바꿀 수 있다 (상)
- FR-11 거래 희망 장소는 교내 건물 목록에서 고른다 (중)
- FR-12 사용자는 부적절한 매물을 신고할 수 있다 (중)
- FR-13 거래완료된 매물은 기본 목록에서 숨긴다 (하)

## 비기능 요구사항
- NFR-01 앱 첫 화면은 3초 안에 표시된다
- NFR-02 사진은 업로드 전에 긴 변 1600px로 압축한다
- NFR-03 학번은 저장하지 않고 이메일과 닉네임만 저장한다
- NFR-04 계좌번호는 암호화해서 저장하고 거래 상대에게만 보여준다

## 범위 밖 (이번 학기)
교재 가격 추천, 스터디 매칭, 관리자 웹 페이지는 하지 않는다.

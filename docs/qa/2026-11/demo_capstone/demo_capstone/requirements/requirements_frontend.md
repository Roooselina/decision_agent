# 프론트엔드 요구사항

담당: 준호, 하은 / 마지막 수정 2026-10-21

## 공통
- FE-01 앱은 Flutter로 개발하고 Android를 먼저 지원한다
- FE-02 메인 색상은 파란색(#2F6FED), 보조 색상은 회색 계열을 쓴다
- FE-10 글자 크기는 시스템 글꼴 크기 설정을 따른다
- FE-11 빈 화면에는 안내 문구와 다음에 할 행동 버튼을 보여준다

## 화면별
- FE-03 로그인 화면에는 학교 구글 계정으로 로그인 버튼 하나만 둔다
- FE-04 매물 목록은 무한 스크롤로 한 번에 20개씩 불러온다
- FE-05 매물 등록 화면에서 사진은 최대 3장까지 첨부할 수 있다
- FE-06 매물 상세 화면의 사진은 가로 스크롤로 넘겨 본다
- FE-07 쪽지 화면은 앱이 열려 있는 동안 10초마다 새 쪽지를 불러온다
- FE-08 거래 화면에는 판매자 계좌번호와 복사 버튼을 보여준다
- FE-09 푸시 알림을 누르면 해당 쪽지나 거래 화면으로 바로 이동한다
- FE-12 사진을 압축하는 동안 진행률을 보여준다

## 참고
디자인 시안은 피그마 BookSwap 파일의 v3 페이지 기준. 하단 메뉴 구조는 아직 정해지지 않아서 이 문서에 넣지 않았다.

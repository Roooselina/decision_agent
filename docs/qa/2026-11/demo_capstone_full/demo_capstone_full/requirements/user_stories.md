# 사용자 스토리

형식: 누구로서, 무엇을 하고 싶다, 왜냐하면. 작성 도윤, 검토 은정.

## 가입과 로그인
- US-01 학생으로서 학교 구글 계정으로 바로 로그인하고 싶다, 비밀번호를 따로 만들기 싫으니까

## 판매
- US-02 판매자로서 교재 사진을 최대 5장까지 올리고 싶다, 필기 상태까지 보여줄 수 있으니까
- US-08 판매자로서 예약중 표시를 하고 싶다, 같은 질문이 계속 오는 걸 막고 싶으니까
- US-11 판매자로서 거래가 끝난 매물을 목록에서 숨기고 싶다

## 구매
- US-03 구매자로서 과목명으로 교재를 찾고 싶다, 책 제목을 정확히 모를 때가 많으니까
- US-04 구매자로서 판매자에게 쪽지로 가격과 장소를 물어보고 싶다
- US-06 구매자로서 판매자 계좌번호를 거래 화면에서 바로 복사하고 싶다
- US-07 구매자로서 판매자와 실시간 채팅방에서 바로바로 대화하고 싶다
- US-09 학생으로서 거래 장소를 교내 건물 중에서 고르고 싶다, 처음 보는 사람과 밖에서 만나기 싫으니까

## 알림과 안전
- US-05 판매자로서 새 쪽지가 오면 푸시 알림을 받고 싶다
- US-10 사용자로서 이상한 매물을 신고하고 싶다

## 나중에 (MVP 아님)
- US-12 신입생으로서 학과별로 많이 거래된 교재를 보고 싶다

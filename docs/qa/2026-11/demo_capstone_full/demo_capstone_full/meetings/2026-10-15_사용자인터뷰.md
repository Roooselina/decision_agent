# 2026-10-15 사용자 인터뷰 정리

진행: 하은, 도윤 / 장소: 학생회관 라운지 / 대상: 학부생 5명 (1학년 2, 3학년 2, 4학년 1)
작성: 도윤

## 물어본 것
1. 교재를 사고판 경험
2. 거래할 때 불편했던 점
3. 매물 사진은 몇 장 정도 보고 싶은지
4. 앱 시안 첫인상 (홈, 매물 상세)

## 답 요약
- 5명 모두 교재 중고 거래 경험 있음, 주로 에타 장터와 학과 단톡방
- 불편: 답장이 늦음 (3명), 약속 장소 정하기 (2명), 필기 상태를 모르고 삼 (2명)
- 사진: 표지, 목차, 필기 페이지까지 보고 싶다는 답이 많았고 3명은 4장 이상이라고 함
- 첫인상: 파란색이 학교 느낌이라 믿음이 간다는 의견 2명
- 1학년 두 명은 어떤 교재를 사야 하는지 알려주면 좋겠다고 함

## 우리 팀에 주는 의미
- 쪽지 답장이 몇 초 늦는 건 크게 문제 안 될 듯, 몇 시간 늦는 게 문제
- 사진 개수는 이번 주 용량 문제로 정한 3장 제한을 나중에 다시 볼 필요 있음
- 교재 추천은 MVP 범위 밖으로 두고 아이디어 메모에 기록

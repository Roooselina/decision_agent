# 회의 메모 (날짜 적는 걸 깜빡함)

- 발표 연습할 때 타이머 하나 켜 두기
- 슬라이드 폰트는 프리텐다드로 통일하는 게 어떨지
- 데모 폰 두 대 충전 미리 해두기
- 발표자 순서는 은정 다음 준호
- 질의응답 예상 질문 목록 만들기
- 시연 계정 비밀번호는 종이에 적어 오지 말 것
- 발표 복장은 자유, 대신 팀 티셔츠 있으면 좋겠다는 얘기 (하은)
- 노트북 HDMI 젠더 챙기기, 세미나실 프로젝터는 HDMI만 됨
- 시연 영상은 1분 30초 안으로 자르기
- 질문 들어오면 기술 질문은 민재, 화면 질문은 준호가 받기
- 발표 끝나고 피드백은 바로 노션 말고 단톡방에 적기
- 슬라이드 마지막 장에 팀원 역할 표 넣기
- 교재 샘플로 쓸 책 세 권 (자료구조, 운영체제, 선형대수) 하은이 가져오기
- 발표 전날은 다들 밤새지 말기 ㅋㅋ

## 배경
로그인이 구글 SSO로 바뀌어서 인증 흐름부터 다시 그려야 했음. 민재가 화이트보드에 그린 흐름을 사진으로 남김.

## 인증 흐름
1. 앱이 구글 로그인으로 ID 토큰을 받는다
2. 서버가 토큰을 검증하고 hd 값이 학교 도메인인지 본다
3. 통과하면 서버가 자체 액세스 토큰과 리프레시 토큰을 준다
준호가 토큰 저장은 flutter_secure_storage를 쓰겠다고 함.

## 엔드포인트 초안 (민재)
- POST /auth/google 구글 ID 토큰으로 로그인
- GET /listings 매물 목록, page와 size 파라미터
- POST /listings 매물 등록
- GET /listings/{id} 매물 상세
- PATCH /listings/{id}/status 판매중, 예약중, 거래완료

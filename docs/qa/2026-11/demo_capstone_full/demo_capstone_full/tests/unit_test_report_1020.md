# 서버 단위 테스트 결과

작성: 민재 / 2026-10-20

- 테스트 112개 중 109개 통과, 3개 실패

## 통과한 영역
- 구글 ID 토큰 검증과 학교 도메인 확인
- 매물 등록 입력 검증 (가격 0원 제외)
- 쪽지 목록, 보내기, 읽음 처리

## 실패

- 매물 상태를 거래완료에서 판매중으로 되돌릴 수 있음
- 검색어에 특수문자만 있을 때 500 오류

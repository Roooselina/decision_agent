# 신고와 거래 장소 명세

담당: 민재(API), 하은(화면) / 갱신 2026-10-25

## 신고
- SF-1 매물 상세의 더보기 메뉴에서 신고할 수 있다
- SF-2 신고 사유는 교재가 아님, 가격이 이상함, 욕설이나 광고, 기타 네 가지다
- SF-3 같은 매물이 서로 다른 사용자에게 세 번 신고되면 자동으로 숨긴다
- SF-4 숨긴 매물은 팀 관리 계정이 확인 후 되살리거나 지운다

## 거래 장소
- SF-5 거래 희망 장소는 교내 건물 목록에서 고른다 (중앙도서관, 학생회관, 공학관 등 12곳)
- SF-6 건물 목록은 서버에서 내려주고 앱은 목록만 보여준다
- SF-7 학교 밖 장소는 고를 수 없다

## 안내
- SF-8 처음 거래할 때 교내 공공장소에서 낮에 만나라는 안내를 한 번 보여준다

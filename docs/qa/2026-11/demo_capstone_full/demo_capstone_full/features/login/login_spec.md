# 로그인 기능 명세

담당: 민재(서버), 준호(앱) / 갱신 2026-10-07

## 흐름
- LG-1 앱은 구글 로그인으로 ID 토큰을 받아 서버의 /auth/google로 보낸다
- LG-2 서버는 ID 토큰의 서명과 만료를 확인하고 hd 값이 학교 도메인인지 본다
- LG-3 학교 도메인이 아니면 403과 함께 학교 계정만 쓸 수 있다는 문구를 돌려준다
- LG-4 통과하면 서버가 액세스 토큰(1시간)과 리프레시 토큰(14일)을 발급한다
- LG-5 앱은 토큰을 기기의 보안 저장소에 둔다

## 첫 로그인
- LG-6 처음 로그인한 사용자는 닉네임만 정하고 바로 홈으로 간다
- LG-7 학번, 실명은 받지 않는다

## 로그아웃과 탈퇴
- LG-8 로그아웃하면 기기의 토큰을 지우고 로그인 화면으로 간다
- LG-9 탈퇴하면 매물은 숨기고 쪽지 기록은 상대에게 탈퇴한 사용자로 보인다

## 예외
- LG-10 구글 로그인 창을 닫으면 아무 일도 하지 않고 로그인 화면에 남는다
- LG-11 네트워크가 끊기면 다시 시도 버튼을 보여준다

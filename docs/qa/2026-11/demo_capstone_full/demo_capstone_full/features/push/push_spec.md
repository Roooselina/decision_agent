# 푸시 알림 명세

담당: 민재 / 갱신 2026-10-24

- PS-1 푸시는 FCM으로 보낸다
- PS-2 알림 종류는 새 쪽지, 거래 요청(예약중 변경), 매물 신고 처리 결과 세 가지다
- PS-3 앱이 화면에 떠 있으면 푸시 대신 앱 안 배너로 보여준다
- PS-4 알림을 누르면 해당 쪽지방이나 매물 화면으로 이동한다
- PS-5 기기 토큰은 로그인할 때와 토큰이 바뀔 때 서버에 등록한다
- PS-6 로그아웃하면 서버에서 그 기기 토큰을 지운다
- PS-7 밤 11시부터 오전 8시까지는 소리 없이 보낸다
- PS-8 내 정보 화면에서 알림 종류별로 끌 수 있다

## 알려진 문제
토큰이 바뀔 때 서버 반영이 안 되는 경우가 있음 (#18). 중간 점검 전까지 고치는 것이 목표.

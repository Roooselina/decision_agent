# 거래 기능 명세

담당: 준호(화면), 민재(API) / 갱신 2026-10-12 (결제 제외 반영)

## 원칙
- TR-1 앱은 돈을 받거나 보내지 않는다. 대금은 구매자가 판매자 계좌로 직접 이체한다
- TR-2 거래 화면에는 판매자의 은행 이름과 계좌번호, 복사 버튼이 있다
- TR-3 계좌번호는 그 매물에 쪽지를 주고받은 구매자에게만 보인다

## 흐름
- TR-4 판매자가 구매자를 정하면 매물이 예약중이 된다
- TR-5 직접 만나 책을 건넨 뒤 판매자가 거래완료를 누른다
- TR-6 거래완료 후 구매자에게 거래 후기 한 줄을 남길 수 있게 한다

## 안내 문구
- TR-7 거래 화면 위에 앱이 대금을 보관하지 않는다는 안내를 항상 보여준다
- TR-8 이체 전에 책 상태를 직접 확인하라는 문구를 보여준다

## 하지 않는 것
- 앱 안 결제, 에스크로, 환불 처리는 이번 학기 범위가 아니다

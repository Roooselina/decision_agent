# 쪽지 기능 명세

담당: 민재(API), 준호(화면), 하은(시안) / 갱신 2026-10-14

## 기본
- MS-1 쪽지는 매물 하나에 대해 구매 희망자와 판매자 둘 사이에만 오간다
- MS-2 쪽지 목록은 상대 닉네임, 매물 제목, 마지막 쪽지, 안 읽은 개수를 보여준다
- MS-3 쪽지는 글자만 보낼 수 있고 500자까지

## 새 쪽지 가져오기
- MS-4 앱이 화면에 떠 있는 동안 10초마다 새 쪽지를 서버에 묻는다
- MS-5 앱이 백그라운드로 가면 묻는 것을 멈추고, 새 쪽지는 푸시 알림으로 알린다
- MS-6 쪽지 상세를 열면 그 대화의 쪽지를 읽음으로 바꾼다

## 표시
- MS-7 상대가 읽으면 내 쪽지 옆에 읽음이 보인다
- MS-8 입력 중 표시는 하지 않는다

## 막기
- MS-9 상대를 차단하면 더 이상 쪽지를 받지 않는다
- MS-10 신고된 매물의 쪽지방은 읽기 전용이 된다

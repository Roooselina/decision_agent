# 검색 기능 명세

담당: 민재(API), 준호(화면) / 갱신 2026-10-21

- SR-1 검색어는 교재 제목과 과목명에서 찾는다
- SR-2 결과는 최신 등록순, 거래완료 매물은 빼고 보여준다
- SR-3 검색어가 두 글자 미만이면 검색하지 않고 안내한다
- SR-4 최근 검색어는 기기에 최대 10개 저장하고 지울 수 있다
- SR-5 결과가 없으면 비슷한 과목명 세 개를 추천한다
- SR-6 초성으로도 찾을 수 있게 한다 (예: ㅈㄹㄱㅈ로 자료구조)
- SR-7 띄어쓰기가 달라도 찾는다 (운영 체제와 운영체제)
- SR-8 검색 결과 한 페이지는 20개

## 진행
제목과 과목명 검색은 동작한다. 초성 검색과 띄어쓰기 무시는 중간 점검 이후 작업 (이슈 #15, #16).

## 하지 않는 것
- 가격 범위 필터, 지도 검색은 이번 학기에 하지 않는다

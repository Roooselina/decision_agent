# BookSwap 서버 배포 가이드

작성: 민재 / 최종 수정 2026-10-23

## 1. 서버
- 운영 서버는 AWS Lightsail 서울 리전 2GB 인스턴스를 사용한다
서버 접속 정보와 키는 팀 드라이브 보안 폴더에만 있다. 저장소에는 절대 올리지 않는다.

## 2. 준비
- JDK 17과 Gradle 8이 필요하다
- 환경 변수 목록은 팀 드라이브의 env 문서를 따른다 (DB 주소, 구글 OAuth 클라이언트 ID, FCM 서버 키)

## 3. 배포 순서
1. main 브랜치에 머지되면 GitHub Actions가 테스트와 빌드를 돌린다
2. 빌드가 통과하면 배포 작업을 실행한다
3. 배포 후 /health 응답이 200인지 확인한다
4. 앱의 API 주소는 api.bookswap.example.com 그대로 둔다

## 4. 되돌리기
- 문제가 생기면 직전 버전으로 되돌린다
- DB 마이그레이션은 되돌리지 않는다, 필요하면 민재에게 먼저 말한다

## 5. 비용
- 서버 비용은 학과 지원금으로 처리하고 매달 은정에게 영수증을 공유한다

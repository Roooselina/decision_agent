# 백업 영상 녹화 계획

시연이 실패할 때 틀 영상이다. 실제 시연과 같은 7단계를 같은 순서로 1번 녹화한다(약 3~4분).
녹화는 Windows 기본 캡처 도구(`Win+Shift+R`, 화면 녹화)나 Xbox Game Bar(`Win+Alt+R`)로 하면 된다.
녹화한 화면은 실제 동작 그대로이며, 발표에서 틀 때는 "미리 녹화한 실제 화면"이라고 말한다.

## 녹화 전

1. `powershell -ExecutionPolicy Bypass -File tools\demo_preflight.ps1` 로 "시연 가능"을 확인한다.
2. `powershell -ExecutionPolicy Bypass -File tools\demo_reset.ps1` 로 폴더와 캐시를 시연 시작 상태로 만든다.
3. 화면 정리: 다른 창, 알림을 끈다(방해 금지). 앱 창은 최대화하고 확대 비율은 100% 또는 125%로 둔다.
4. 개인 정보: 메일 화면에 실제 주소가 보이면 샘플 계정만 보이게 하거나 그 부분을 녹화 범위 밖에 둔다.
   설정의 키 칸과 "내 정보"의 계정 줄은 열지 않는다.
5. 메모장에 `requirements\requirements_frontend.md` 를 열어 둔다(FE-05 줄이 보이게).
6. 라이브 메일을 보낼 네이버 메일 쓰기 화면을 휴대폰이나 다른 창에 준비한다(DEMO_SHEET.md 6단계 문구).

## 녹화할 것 (순서대로)

| 단계 | 화면 | 손으로 할 것 | 녹화에 담을 것 |
|---|---|---|---|
| 1 | 홈 | 그대로 둔다 | 폴더 카드(각 폴더 상태), 메일과 캘린더 연결 표시, 시연 폴더 "검사 완료" |
| 1 | 점검 결과 | 결과 탭을 연다 | 반영 안 됨 10줄: 파일, 줄, 바뀐 결정 |
| 2 | 결과 상세 | FE-05(사진 3장) 줄을 연다 | 옛 값, 파일과 줄, 바뀐 결정 문장과 그 출처 회의록 |
| 3 | 메모장 | FE-05의 `3장` 을 `5장` 으로 고치고 저장 | 저장 후 앱으로 돌아와 진행 표시, FE-05 지적이 사라지는 것, 다시 본 줄 수 |
| 4 | 메일 | 네이버에서 라이브 메일을 보낸다 | 메일 화면에 새 메일이 버튼 없이 나타나는 것, 이어서 FE-02(파란색) 새 지적 |
| 5 | 확인 질문 | 질문이 있으면 열고 답한다 | 질문 문장, 답한 뒤 질문이 사라지는 것 |
| 6 | 메일 보내기(선택) | 지적 하나에서 "메일로 알리기" 후 보내기 클릭 | 받는 사람이 본인 두 번째 주소인 것, 보낸 뒤 상태 |
| 7 | 설정, 홈 | 점검 수준(정밀, 균형, 절약), 확인 기준, 폴더별 상태를 보여 준다. 홈에서 "지금 점검" | 바뀐 것 없는 재점검이 바로 끝나고 요청 0회 |

## 녹화 후

- 영상을 처음부터 끝까지 한 번 보고 실제 주소, 키, 개인 경로가 보이지 않는지 확인한다.
- 파일 이름 예: `시연_백업_2026-11-xx.mp4`. 발표 노트북 바탕화면과 USB에 하나씩 둔다.
- 다시 시연 상태로 돌리려면 `tools\demo_reset.ps1` 을 한 번 더 실행한다(FE-05가 3장으로 돌아간다).
  라이브 메일은 Gmail에 남으므로, 두 번째 녹화나 리허설에서는 메일 단계가 "이미 받은 메일"로 보인다.
  메일 단계를 다시 보이려면 DEMO_SHEET.md의 "메일 단계 되돌리기"를 따른다.
